## 2024-07-20 - React Array Allocations in getters and useMemo
**Learning:** In this React codebase, housing O(N) operations like `.map()`, `.filter()`, and `.reduce()` inside `useMemo` calculation blocks (or getter functions) is an anti-pattern because the chained methods still execute and allocate intermediate arrays on every single render cycle when dependencies change. This creates unnecessary garbage collection overhead for components processing large datasets (like inventory records or sales data).
**Action:** Always pre-calculate totals or transformations directly using traditional `for` loops inside the `useMemo` block. This single-pass calculation avoids multiple array allocations and significantly improves memory usage during heavy render cycles, especially for list and reporting components.
