## 2024-07-27 - Dashboard rendering performance optimization
**Learning:** A codebase-specific performance pattern in this React application is to avoid housing O(N) operations (like 'reduce' or 'filter') inside getter functions of memoized arrays, as they will still execute on every render when mapped. Instead, pre-calculate these totals directly inside the 'useMemo' block using standard 'for' loops to minimize garbage collection and array allocations.
**Action:** Always check memoized arrays that return getter functions to ensure expensive O(N) operations aren't hidden inside the getters, and refactor them to use standard 'for' loops within the 'useMemo' hook.
